# Monteiro Add-ons

Monteiro Add-ons shows the add-ons of the repositories installed in Kodi in the design of the Monteiro add-ons. The repositories are on the left, and their add-ons are on the right, in one list instead of the categories of Kodi.

## Features

- **All repositories** first, then one entry for each repository, with the number of add-ons in it.
- Each add-on shows its icon, name, summary and version, and on the right its category, such as **Look and feel**, **Program add-ons** or **Video add-ons**, in the language of Kodi.
- Installed add-ons have a green check after their version, and those with a newer version also say **Update available**.
- OK on an add-on shows its details: icon, name, version, author, category, description and screenshots, with buttons to install it, or to open it and change its settings when it is installed. OK on a screenshot shows it in full screen.
- Search looks for words in the names and summaries of the add-ons of every repository.
- Modules that other add-ons use are left out, as Kodi does.
- Interface in English and Brazilian Portuguese.

## Using Monteiro Add-ons

| Key | On the repositories | On the add-ons |
| --- | --- | --- |
| **Up / Down** | Move between repositories. | Move between add-ons. |
| **Left / Right** | Left reaches the toolbar. Right moves to the add-ons. | Left returns to the repositories. |
| **OK** | Show the add-ons of the repository. | Show the details of the add-on. |
| **Hold OK**, or **Menu** (**C** on a keyboard) | | Options: **Install**, **See the updates**, **Open** and **Settings**. |
| **Back** | Close Monteiro Add-ons. | Return to the repositories. |

Kodi asks before installing an add-on and installs the add-ons it needs too. Updates are installed from the list of updates of Kodi, which **See the updates** opens.

The toolbar above the repositories has **Search** and **Update repositories**. Update repositories asks Kodi to check every repository for new add-ons and versions, and shows the list again when the check has had time to finish.

## With the Monteiro skin

**Repositories** in the add-on browser of the Monteiro skin opens Monteiro Add-ons, and the skin installs it with itself. `RunScript(script.monteiro.addons,repository.id)` opens it on one repository.

## Development

| Path | Purpose |
| --- | --- |
| `default.py` | Opens the main window, on the repository given as its argument. |
| `resources/lib/gui.py` | Main window, search, installing and the options of an add-on. |
| `resources/lib/catalog.py` | Reads the repositories and their add-ons from the add-on database of Kodi, read only, and gives each add-on its category. It does not import Kodi modules and can be tested with a regular Python 3 interpreter on a copy of the database. |
| `resources/skins/default/` | Window layout and icons. |

The window layout is generated by `tools/generate_monteiro_addons_skin.py`, with the palette and parts of the Easy Channel generator. The icon, fanart and header symbol are drawn by `tools/generate_monteiro_addons_art.py`, which needs Pillow and the [Inter](https://rsms.me/inter/) font.
